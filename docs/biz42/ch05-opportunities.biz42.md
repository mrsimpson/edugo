## Frontend-only DSGVO framing

Tools that run entirely in the browser with no backend are structurally incapable of exfiltrating student data — yet this framing does not yet exist in the school adoption conversation. edugo can pioneer a "frontend-only = DSGVO-safe by design" badge that unlocks immediate classroom adoption without bureaucratic review.

:::opportunity
